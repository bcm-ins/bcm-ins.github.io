2026-11-02。延续 [框架调研](FRAMEWORK_RESEARCH.md) 的 Astro + GitHub Discussions + Workers 架构。

## 落地规则

- 白底，细灰边框，蓝色用于选中和主要操作；无宣传口号。
- 链接、按钮、标签、摘要开关和输入控件都有可见边界，悬停、键盘焦点及选中状态可区分。
- 首页左侧导航、中央文章流、右侧板块上下文；窄屏变单列，主要入口仍可访问。
- 文章第一段显示多板块标签。知识、问题、固件 / 软件发布共用 Markdown 阅读结构。
- 阅读、主回复、跟帖、预览、修改、点赞、采纳在同一文章页完成。删除有明确确认；锁定或关闭的文章禁写。
- 个人页显示公开文章、已同步回复；本人另有本机草稿及编辑入口。草稿仅保存在当前浏览器，不上传或伪称跨设备同步。
- 登录跳转 GitHub 授权一次后返回当前站内页面；其他用户点击作者名称进入本站个人页。

## 数据与边界

匿名读者查看 Actions 导出的完整公开回复快照；登录读者通过 Worker 实时读取并分页。新回复立即出现在当前页面，匿名页面和个人页的回复历史等待 Actions 同步。GitHub 搜索索引也可能短暂延迟。

GitHub 回复模型支持主回复与一层跟帖。本站据此展示，不制造任意深度线程。原文入口放在可折叠的同步信息中。通知、举报、置顶、锁帖等高级管理仍使用 GitHub；本站提供权限允许的采纳和本人内容修改 / 删除。

公开同步设置显式容量上限，超限阻止构建而不静默丢内容。后台检查仓库与文章归属、作者权限、锁定状态、限流及提交幂等；浏览器和静态生成均清理 Markdown 中的危险 HTML。

## 验收

自动测试包含实际打包前端脚本的 DOM 交互、双击防重、回复编辑、个人页与草稿、内容清理、后端跨文章权限、锁帖、分页和不确定网络结果。实际 GitHub 只读查询单独验证 schema 与数据。

用户 Edge 的自动化在读取窗口时被工具停止，原因是无法可靠识别当前网址；未读取浏览器令牌或绕过检查。此次新增回复的真实用户会话提交不能据此声称已通过。既有生产数据库仅查询非敏感元数据，确认此前 OAuth 会话及本站发文 #4 已成功。
